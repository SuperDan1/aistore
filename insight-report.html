Where Things Go Wrong

Analysis of interrupted workflows and friction points.

Arc<BufferMgr> Mutability Issues
Buffer pool integration blocked by Arc not providing mutable access. Required changing to Arc<Mutex<BufferMgr>> for interior mutability.
  • Original: `Arc` stored but never used
  • Fix: Changed to `Arc>` pattern
  • Impact: Required updates to storage.rs and executor/mod.rs
segment_id Validation Errors
5 catalog tests failed due to segment_id=0 being invalid. TableBuilder requires segment_id > 0.
  • Test loops starting from i=0 caused validation failures
  • Fix: Changed to `i + 1` offset
  • Also fixed concurrent test race conditions with relaxed assertions
Packed Struct Compiler Errors
PageHeader packed struct had trait derivation issues with Copy/Clone.
  • #[repr(packed)] + derive macros incompatible
  • Fix: Manual trait implementation instead of derive
Benchmark False Positives
Initial benchmark showed 30M TPS but was misleading - each thread had independent StorageEngine instance, not sharing data.
  • 10 threads = 10 independent buffer pools
  • No real lock contention measured
  • Fix: Refactored to use global singleton
